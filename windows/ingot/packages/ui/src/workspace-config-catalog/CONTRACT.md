
ProjectService拥有 roots，Catalog 只读Project与仍Retain的远端入口，按 workspace identity/path 去重，不从 tab orOld settings 集合推导Table of ContentsMembers。不ReadTask、不创建Project/Agent/Connect，未打开 tab 的 root 可Configuration。

Request前后校验 Host membership 与入口 ID，丢弃Delete/重加后的迟到远端Result。UI 只持有ReadResult与加载Status；state:projects 通知触发重读。ReadFailed不沿用另One Host 的ConfigurationTarget。

Desktop 远端Configuration复用已有 Source settings attachment；仅在选Medium远端且无 logical attachment 时Request它。手机Continue使用可Letter shared-host workspace attachment，不能借此Request Source settings orStart独立 Host。Configuration hooks 与 conversation hooks 分开，后者不能获得Configuration专用Service集合。

模块依赖既有 UI 的 tab 类型、workspace hooks、Configuration attachment store 与 logger；这些Yes适配入口，不New增Table of Contents事实源。
