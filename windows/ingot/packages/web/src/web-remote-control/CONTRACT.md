# web-remote-control

Mobile Remote Control admission、Devicelist、transport 与只读Pages。

入口Passed auth/HTTP/location/storage 端口操作outer部Status；契About的Devicegrouping与Cache展示类型不依赖Implementation。entry 的 AbortSignal 控制本次导航；transport 的 socket/generation 控制Connect。只提取帧解析与独立Request关联，不创建第Two份恢复 owner。Main/Host/CLI Continue拥有业务Status，手机仍为 replayable。

bootstrap Request只Read响应。version guard 校验CurrentRequest代际与Version后，同步Passed `onAccepted` SubmitView epoch 等接受副作用；Invalid、释放orVersion不匹配的回包不得产生该副作用。

Complete语义见 [Relay V2 spec](../../../../docs/web-remote-control/relay-v2-pairing.md)。
