关于 · About the Studio

在材料与场景
之间，构造静止。

虚白成立于 2017 年的上海，YesOne家由六位Design师组成的小型工作室。我们关心One件Portfolio在Final落地之前，材料、场景与时间如何共同塑造它的样貌——而非追逐某种风格的表层。 我们Service过博物馆、出版机构、艺术空间、独立Brand与艺术家个体。无论Project规模与媒介如何变化，我们倾向于先观察、再回应；先减法、再装饰。 从 2020 年From，我们在京都设立了第Two个工作站，与One位驻地匠人合作Completed所有的物料与原型工作。
