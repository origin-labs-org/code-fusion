## 🛡️ SAFETY & LIMITATIONS

### Safety Guards:
- ✅ Auto-pause at cost thresholds ($50, $100, $200)
- ✅ Auto-pause at time thresholds (1h, 24h, 7d)
- ✅ Stuck detection (same score 10x in a row)
- ✅ Emergency stop (Ctrl+C or `/gauntlet-stop`)
- ✅ State persistence (resume after interruption)

### Known Limitations:
- ⚠️ Gauntlet can be expensive (many API calls)
- ⚠️ Never-surrender mode may run for WEEKS
- ⚠️ High quality = high token usage per iteration
- ⚠️ Some skills require external tools (git, npm, etc.)

### Recommendations:
1. Use `--quality standard` for daily work
2. Reserve `never_surrender` for truly important challenges
3. Always set `--max-cost` if budget-conscious
4. Check progress regularly with `/gauntlet-status`
5. Use `/cost` to monitor spending
