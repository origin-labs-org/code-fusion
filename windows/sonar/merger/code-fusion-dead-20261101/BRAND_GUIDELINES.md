# CodeFusion Brand Guidelines

To maintain the healthy development of the CodeFusion ecosystem, avoid user confusion, and facilitate resource discovery:

- In descriptive text, you may use "CodeFusion" to describe your project's relationship, e.g. "built on CodeFusion" or "compatible with CodeFusion".
- For package and project naming, use the abbreviated **CF** designation (npm scope `@origin-ai/cf-*`, CLI `cf`).
- Avoid using the full "CodeFusion" trademark as a standalone project name in a way that implies official endorsement, cooperation or authorization.
- Do not use official brand materials in a way that implies official endorsement, cooperation or authorization.

Origin AI maintains the CodeFusion distribution. The UI and architecture lineage traces to an internal harness reference; public branding in this distribution is CodeFusion / CF. No third-party model-provider branding, logo, or attribution ships in the public surface.

We may contact parties that do not comply to coordinate adjustments. Thank you for helping keep the ecosystem clear and sustainable.
