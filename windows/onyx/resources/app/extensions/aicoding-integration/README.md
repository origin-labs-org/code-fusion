# AI Publish Integration

AI-powered publishing integration for Qoder IDE.

## Features

- AI-assisted content publishing
- Configuration-driven publishing workflow
- Seamless integration with Qoder ecosystem

## Commands

- `AI Publish: Start AI Publishing` - Start the AI publishing process

## Configuration

- `aicoding.publish.enabled` - Enable/disable AI publish integration (default: true)

## Requirements

- Qoder IDE (VS Code based)
- Node.js runtime

## Extension Settings

This extension contributes the following settings:

* `aicoding.publish.enabled`: Enable/disable AI publish integration
